# 🍕 Pizza Hub

A modern restaurant menu website built with **Python** and **Streamlit**.

## 🌐 About the Project

Pizza Hub is an interactive restaurant menu where customers can explore different food categories, select product sizes, choose quantities, and calculate prices in Egyptian Pounds (EGP).

## ✨ Features

- 🍕 **Pizza Menu** – Explore different pizza options.
- 🍝 **Pasta Menu** – Choose from a variety of pasta dishes.
- 🥤 **Drinks Menu** – Browse refreshing drinks.
- 📏 **Size Selection** – Choose between Small, Medium, and Large where available.
- 🔢 **Quantity Selection** – Select the desired quantity.
- 💰 **Price Calculator** – Calculate the total price instantly.
- 🎨 **Custom Design** – Colorful interface with a restaurant-inspired theme.

## 🛠️ Technologies Used

- Python
- Streamlit
- HTML
- CSS

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/karimahmedomar88/pizza-hub.git
   ```

2. Open the project folder:

   ```bash
   cd pizza-hub
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```
